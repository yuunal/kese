# Kese – APK kurulumu (Google Cloud gerekmez)

1. github.com'da ücretsiz hesap açın → sağ üstte **+ → New repository** → adı `kese`, Public → Create.
2. Açılan sayfada **uploading an existing file** bağlantısına tıklayın, bu klasörün **içindeki her şeyi**
   (`.github` klasörü dahil) sürükleyip bırakın → **Commit changes**.
   `.github` görünmüyorsa gizli dosyaları göster seçeneğini açın.
3. Üstte **Actions** sekmesi → soldaki **APK derle** → **Run workflow**. Yaklaşık 5-8 dk sürer.
4. Bittiğinde çalıştırmaya tıklayın, en altta **kese-apk** çıktısını indirin. Zip'ten `app-debug.apk` çıkar.
5. APK'yı telefona aktarıp kurun (bilinmeyen kaynaklara izin vermeniz istenir).

## Yedekleme
- Bütçe sekmesi → **Yedekle** → Drive'ı, e-postayı veya başka bir uygulamayı seçin.
- Yeni telefonda **Yedekten geri yükle** ile dosyayı seçin.
